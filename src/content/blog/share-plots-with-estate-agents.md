To share property listings with agents and keep track of the results, give each agent their own link to the same live listing. The link should send the buyer's enquiry to that agent, carry the agent's contact on anything the buyer downloads, and show availability that your team keeps up to date in one place. Then nobody sells a plot that is already reserved, and every enquiry has a name next to it.

## Why agent sharing goes wrong

Many developers sell through their own team and outside agents. Each agent gets the layout plan, a price list and photos as files in a chat. Now there are as many copies of the estate as there are agents.

Three problems follow:

- **The copies go out of date.** You reserve a plot on Monday. An agent shows it to a buyer on Wednesday from last month's price list.
- **Enquiries get lost.** A buyer forwards the files to a cousin, who calls the number on your website. Nobody knows which agent started the conversation.
- **Agents argue about credit.** Two agents say they brought the same buyer, and there is no record either way.

None of this is the agents' fault. The information has no single home.

## One source, many links

The fix is simple to describe: keep one version of the estate, and give each agent a different way in.

That one version holds every plot's status (for sale, reserved or sold), size and price. Your team updates it. Agents never edit it, and never keep their own copy. Each agent shares a link that opens the same estate, with something in the link that says whose it is.

Usually that is a short code at the end of the address. It does three jobs:

1. **It decides who the enquiry goes to.** A buyer who taps "enquire" on an agent's link should reach that agent, not a general inbox.
2. **It puts the agent's contact on anything the buyer saves.** If the buyer downloads a brochure or a plot summary, it should show the agent's name and number, so the agent is still the contact when the buyer comes back weeks later.
3. **It survives sharing.** If the buyer forwards the link to family, the code should travel with it.

If your tools can't do this, you can still get close by hand: give each agent a slightly different contact form or a separate tracking link, and ask buyers how they heard about you.

## Send buyers to one plot, not the whole estate

Buyers rarely ask about an estate in general. They ask about a plot: "Is 108 still available?" The best reply is a link that opens that plot, with its size, price and status already on screen.

It saves the buyer from searching a map. When an agent sends it, the agent's code should stay in the link, so the enquiry from that plot still reaches them.

## Make the enquiry message do the work

When a buyer enquires, the message should already say what they want. A blank "Hi" in a chat tells the agent nothing. A ready-written message such as "I'm interested in plot 108 at Hillcrest Gardens. Please send me more details", with a link back to the plot, tells them everything. (Hillcrest Gardens is the name of our fictional demo estate.)

Two small things help:

- **Name the plot and the estate in the message.** The agent can answer straight away, without asking which plot.
- **Name the agent too, if your tools allow it.** If the message arrives at the wrong inbox, the agent is still in the text, so it can be passed on and credited.

## Keep availability current, in one place

Agent links only help if what they show is true. A buyer who falls for a plot that is already sold loses trust in everyone.

Some habits that work:

- **One person or role owns status changes.** Everyone else asks them. Changes are made the same day a deposit is paid or a plot is reserved.
- **Reserved is its own status.** It tells agents to stop promoting the plot without pretending it's sold.
- **Prices change in the same place.** If a phase goes up in price, the links show it as soon as it's saved, and no old price list survives in a chat.
- **Agents never send screenshots of availability.** Screenshots don't update. Links do.

## Keep a simple record of enquiries

Even with agent links, keep a short record of each enquiry: the date, the buyer's name, the plot, the agent, and what happened next. A shared spreadsheet is enough. Ask agents to add a line for every enquiry they get from their link.

It settles credit, shows which agents are active, and tells you which plots buyers ask about most.

## Decide what agents can and can't do

Agents need less access than your own team:

- **Your team** (owners and staff) edits plots, prices and statuses, and decides who can see the estate.
- **Agents** share links and answer buyers. They don't change availability, and they don't see internal documents such as surveyor's plans or contracts.
- **When an agent stops working with you**, switch their access off. New enquiries from their old links should come back to your own sales team.

## In short

**How do I share property listings with agents?**
Keep one live version of the estate and give each agent their own link to it, with a code that says whose link it is.

**How do I know which agent an enquiry came from?**
Use links that send the enquiry to the agent who shared them, name the agent in the message, and keep a simple record of every enquiry.

**How do I stop agents selling plots that are already gone?**
Update status in one place on the day it changes, use a Reserved status, and share links instead of price lists and screenshots.
