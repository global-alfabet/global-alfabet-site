# Global Alfabet brand files

Logos for Global Alfabet and every Alfa product. SVG is the master; PNGs are ready to upload anywhere.

## Which file to use

| File | Use it for |
| --- | --- |
| `*-icon.svg` / `.png` (1024, 512, 180) | App icon, website favicon and app tiles, product rows |
| `*-avatar.png` | Social media profile picture (square, safe for circle crops) |
| `*-lockup-light` | Logo with name on white or light backgrounds |
| `*-lockup-dark` | Logo with name on black or dark backgrounds |
| `*-lockup-white` | All-white logo on photos or the brand colour |
| `*-banner-3x1.png` | Social header or web banner (3000 × 1000): white logo on the brand colour |
| `*-glyph-white` | The symbol alone, white, for posts and overlays |
| `global-alfabet-glyph-color` / `-black` | The GA monogram alone in blue, or one colour for stamps and print |
| `global-alfabet-lockup-tagline-*` | Logo with "Providing access" |

## Rules

- Keep clear space around a logo equal to the height of its capital letters.
- Do not recolour, stretch, outline or add effects. The tile gradient is part of the icon.
- The yellow window is the family signature: never remove it.
- Product names are always written in full in text: Alfa Maps, Alfa Finda, Alfa Shop.
- Type: Inter Display SemiBold (logos, headings), Inter Regular (text).
